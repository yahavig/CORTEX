# CORTEX

**C**ontent **O**perations, **R**eels, **T**racking & **EX**penses — מערכת מקומית לניהול העבודה כיוצר תוכן. התוכנית המלאה: [PLAN.md](PLAN.md).

## איך זה רץ

- שרת Node מקומי ב־`http://127.0.0.1:4747` שמגיש גם את ה־UI. רץ ברקע דרך launchd, עולה עם ההתחברות למק ומתאושש מקריסות.
- הכול יושב בתיקייה הזו: קוד, DB, גיבויים ולוגים.
- ה־DB הפעיל: `data/live/cortex.db`. מוחרג מסנכרון iCloud, כי סנכרון של SQLite פתוח יכול להשחית אותו.
- גיבוי יומי ל־`data/backups/`, נשמרים 14 אחרונים. התיקייה הזו **כן** מסונכרנת, כך ש־iCloud שומר עותק של הנתונים.
- לוגים: `logs/server.log`.
- `data/live`, `logs`, `node_modules` ו־`dist` מוחרגים מ־iCloud (מאפיין `com.apple.fileprovider.ignore#P`). ההחרגה מוחלת מחדש בעליית השרת ואחרי כל `npm install` ו־`npm run build`.

**שחזור מגיבוי:** `npm run service:uninstall`, מעתיקים קובץ מ־`data/backups/` ל־`data/live/cortex.db` (ומוחקים `cortex.db-wal` ו־`cortex.db-shm`), ואז `npm run service:install`.

## מה עובד (שלב 1)

- **לוח תוכן:** שורת רעיונות עם thumbnails (SF Symbol בסקווירקל בצבע התחום), ו־6 עמודות שלבים עם גרירה.
- **כרטיס סרטון:** כל השדות, בחירת אייקון מ־SF Symbols, תיקיית פרויקט מתוך `yahav-brand/videos`, כיתוב עם מונה 2200.
- **מעבר ל"מוכן":** הרינדור האחרון מ־`videos/<slug>/renders` והכיתוב מועתקים ל־`iCloud Drive/מוכן לפרסום/`, ונוצרת תזכורת ברשימה `CORTEX` ב־Reminders לשעת הפרסום. שינוי שעה או כיתוב מעדכן את שניהם. חזרה לשלב קודם מוחקת את התזכורת, ו"סמן כפורסם" מסמן אותה כבוצעה.
- **לוח שבועי:** משבצות פרסום (ברירת מחדל א׳–ה׳ 18:00, ניתן לשינוי), גרירה של סרטון למשבצת כדי לתזמן.
- **סקירה:** התראות על משבצות ריקות, סרטונים מתוזמנים שעוד לא מוכנים, וזמן פרסום שעבר בלי סימון.
- **עיצוב:** SF Hebrew לעברית, SF Pro לאנגלית (מוגשים מ־`/Library/Fonts`), ואייקונים מ־`yahav-brand/assets/sf-symbols`.

## מה עובד (שלב 2)

- **תסריטים:** Claude Code רץ ברקע (`claude -p`) עם הנוסחה, ספר הלקחים ו־SCRIPT*.md מהפרויקטים הקודמים, ובודק את המחקר ב־WebSearch. מחזיר 3 הוקים, קריינות עם תגיות ElevenLabs, ויזואל לכל שורה, כיתוב ומקור.
- **עורך:** בחירת הוק, עריכת שורות, בדיקת תזמון (סוף ההוק עד ~3 שניות, סוף ההבטחה עד 8), העתקה ל־ElevenLabs, גרסאות.
- **אישור לצילום:** הכיתוב עובר לכרטיס, הכרטיס עובר ל"הקלטה", ו־`SCRIPT.md` נכתב לתיקיית הפרויקט אם היא קיימת.
- **ספר לקחים:** הוספה ידנית, ייבוא מניתוח מודבק (Claude מחלץ הצעות), סטטוסים. נשמר גם ל־`yahav-brand/lessons/lessons.md`.
- **הנוסחה:** ניתנת לעריכה במסך התסריטים, יחד עם קצב הקריינות.
- **דרישה:** Claude Code מחובר. פעם אחת בטרמינל: `~/.local/bin/claude` ואז `/login`.
- **לוגים של משימות:** `logs/jobs/<id>.log`.

## מה עובד: עסק ומשימות

- **משימות:** דף כללי עם תחומים (תוכן, עסק, מנהלה ומס, אישי), תאריך יעד, עדיפות וקישור לסרטון או לשיתוף פעולה. קבוצות: באיחור, היום, מחר, השבוע, בהמשך.
- **הכנסות:** התקבלו ומחכים לתשלום, מט״ח עם שער יציג אוטומטי מבנק ישראל לפי תאריך ההכנסה, עמלות, ניכוי במקור, מספר וקובץ קבלה.
- **הוצאות:** קבלה כקובץ (גרירה), קטגוריה עם אחוז מוכר כברירת מחדל, מע״מ בקבלה (למעבר למורשה), רכוש קבוע, מנויים עם תזכורת לקבלה חודשית.
- **שיתופי פעולה:** pipeline מגרירה, סכום, מסירה, תנאי תשלום, זכויות שימוש. מותגים ואנשי קשר.
- **סקירה:** תקרת עוסק פטור וצפי לשנה, גרף חודשי, כמה להפריש למס ולביטוח לאומי מול המקדמות, מועדים קרובים, מע״מ "אם היית מורשה", מה חסר לפני הדוח.
- **מס והגדרות:** סוג עוסק, מקדמות, נקודות זיכוי, סימולציית רווח, ופרמטרי החוק (ערכי 2025, ניתנים לעריכה).
- **ייצוא לרו״ח:** CSV שנתי של כל ההכנסות וההוצאות.
- **קבצים:** `yahav-brand/business/expenses/YYYY/MM/` ו־`yahav-brand/business/receipts-issued/YYYY/MM/` (מסונכרן ל־iCloud).
- **חשוב:** חישובי המס הם הערכה לתכנון תזרים, לא ייעוץ מס.

## עיצוב

- **מצב בהיר וכהה** לפי הגדרת המערכת של macOS, בלי מתג בתוך האפליקציה (לפי ה־HIG, `dark-mode.md`).
- **צבעים סמנטיים** ב־`src/web/styles.css`: `bg`, `surface`, `elevated`, `fill`, `line`, `ink`, `muted` ו־`neon-*`, עם ערכים נפרדים לכל מצב. אין צבעים קשיחים בקומפוננטות.
- **ניגודיות:** כל צבעי הטקסט עומדים ב־4.5:1 לפחות מול כל משטח, בשני המצבים. צבעי הגרף אומתו לכל מצב.
- **פונטים ואייקונים:** SF Hebrew, SF Pro ו־SF Symbols.
- **גדלים ופרופורציות של apple.com** (getdesign.md/apple, הסקיל `apple-design-system`): טקסט גוף 17, כיתוב 14, הערות 12, כותרות 21 / 28 / 40, משקלים 400 ו־600 בלבד, ריווח אותיות שלילי קל. רדיוסים 5 / 8 / 11 / 18, כרטיסים עם ריפוד 24 ובלי צללים, כפתורי גלולה, שדות בגובה 44.
- **מעטפת:** סרגל צד מקובץ (יצירה, ניהול, הגדרות) שאפשר להסתיר (⌃⌘S), סרגל כלים עם כותרת המסך, וזכוכית רק בשכבה הפונקציונלית (סרגל צד וסרגל כלים), לא על תוכן.
- **מקלדת:** ⌘1 עד ⌘9 לניווט בין המסכים, Esc לסגירת חלוניות, טבעת פוקוס גלויה.
- **נגישות:** מכבד Reduce Motion, Reduce Transparency ו־Increase Contrast.

## מודולים

תכונות חדשות נבנות כמודולים עצמאיים, כדי שאפשר יהיה לשנות או להחליף כל אחד בלי לגעת בשאר:

- שרת: `src/server/modules/<name>/` עם `schema.ts`, `routes.ts`, לוגיקה, ו־`index.ts` שמייצא `Module`. נרשמים ב־`src/server/modules/index.ts` (מחיקת שורה מכבה מודול).
- ממשק: `src/web/modules/<name>/`, ופריט תפריט ב־`src/web/sections.ts`.
- לוגיקה טהורה (בלי DB או רשת) יושבת ב־`src/shared/`, כדי שתוכל לרוץ גם בשרת אחר בעתיד.

מודולים קיימים:
- **receipts** (ממשק בלבד, על נתוני ההכנסות): תשלומים שהתקבלו וצריך להפיק להם קבלה, וקבלות שהופקו. הקבלה עצמה מופקת בתוכנת החשבוניות, ו־CORTEX שומר מספר, תאריך וקובץ.
- **accounts:** חיבור Instagram (טוקן ארוך טווח שמתחדש לבד), ElevenLabs ו־Claude Code. סודות ב־Keychain (שירות `CORTEX`).
- **automations:** כללים בסגנון ManyChat (תגובה, DM, תגובה לסטורי, תיוג), התאמה שמבינה תחיליות בעברית, תצוגה מקדימה ובודק. המנוע שעונה בזמן אמת (webhooks) עוד לא מחובר; יתווסף כשיוחלט איפה הוא רץ.

## פקודות

| פקודה | מה עושה |
|---|---|
| `npm run dev` | פיתוח: שרת עם watch ב־4747, ו־Vite ב־5173 |
| `npm run build` | בונה את ה־UI ל־`dist/web` |
| `npm run service:install` | בונה ומתקין/מפעיל מחדש את השירות ברקע |
| `npm run service:uninstall` | מסיר את השירות (הנתונים נשארים) |
| `npm run db:generate` | יוצר migration אחרי שינוי ב־`src/server/db/schema.ts` |
| `npm run typecheck` | בדיקת טיפוסים |

אחרי שינוי בקוד השרת או ב־UI, מריצים `npm run service:install` כדי שהשירות ירוץ עם הגרסה החדשה. migrations רצות אוטומטית בעליית השרת.

## הוספה ל־Dock

ב־Safari: פותחים `http://127.0.0.1:4747`, ואז **File → Add to Dock**.

## Node

השירות משתמש ב־node שהריץ את `npm install` (כרגע nvm v24). אחרי החלפת גרסת Node: `npm rebuild better-sqlite3 && npm run service:install`.
